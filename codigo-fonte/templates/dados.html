Dados e consultas

Os perfis do diretório também estão descritos em RDF. Esta página reúne os arquivos, as seis perguntas de competência com suas consultas SPARQL e as ligações das áreas de conhecimento com o Wikidata.

Os resultados abaixo foram exportados de uma execução local sobre o conjunto de demonstração (${instituicao}). Não há endpoint SPARQL público.

Arquivos RDF

  • Ontologia de aplicação (OWL em Turtle)

    Classes, propriedades, domínios, alcances e alinhamentos. Prefixo ca:.

  • Instâncias (RDF em Turtle)

    Pessoas, unidades, cursos, disciplinas, áreas, projetos, grupos e publicações gerados a partir do mesmo JSON que produz as páginas. Prefixo inst:.

As URIs usam a base planejada https://pedromota07.github.io/conecta-academico/. A licença CC BY 4.0 foi a escolhida para o conjunto de dados.

Consultas SPARQL

Cada consulta foi executada com RDFLib sobre instancias.ttl, sem inferência. Os parâmetros entram como URIs; valores sem registro aparecem como “Não informado”. PC4 e PC5 percorrem relações entre tipos diferentes de entidade: projeto e pessoas, publicação e autores.

${consultas}

Ligações externas

As áreas de conhecimento locais são conceitos SKOS. Três delas têm correspondência com itens do Wikidata. A URI da entidade (forma canônica publicada pela fonte) é diferente da página que a descreve. Não há ligação de pessoas fictícias com identidades reais.

${ligacoes}

Os dados estruturados do Wikidata estão disponíveis sob CC0 1.0. Os textos das páginas seguem outra licença (condições de uso do Wikidata).

Como reproduzir

No repositório, com Python 3.10 ou superior e o ambiente virtual instalado:

python -B codigo-fonte/gerar_rdf.py --publicaveis docs/ontologia
python -B codigo-fonte/executar_consultas.py
python -B codigo-fonte/executar_consultas.py consulta02 --param curso=curso-biblioteconomia
python -B codigo-fonte/gerar_site.py

A explicação de cada consulta está em documentacao/consultas-sparql.md e a das ligações em documentacao/ligacoes-externas.md, no repositório do projeto.
